# QA rubric — NGO Report & Proposal Pack
*(RP-012 · layer-3 QA · the exact lines the submission letter checks)*

Independent QA reviewer (not a member of the delivery pod). Score each area ≥ 4.0 to pass.

## Acceptance criteria (the client's promise)
- [ ] Every claimed result carries an evidence reference — nothing asserted without a source
- [ ] The donor's formatting rules are met line by line (checklist attached)
- [ ] Arabic and English versions carry the same meaning, confirmed by an independent reviewer
- [ ] Every item in the scope is present and complete

## Quality layer
- [ ] The work meets the standard for content, writing & translation — clear, correct, and usable
- [ ] Every claim, figure, or result carries its source or evidence (the house rule)
- [ ] Scope matches the SOW exactly — nothing silently added or dropped
- [ ] Arabic/English parity confirmed where both are delivered
- [ ] Results language aligned to OECD-DAC criteria vocabulary where the donor uses it; data disaggregated (sex, age, governorate) wherever it exists.

## The gate
If any line scores below 4.0, the work returns to the pod with specific notes before the
submission letter is issued. QA sign-off is attached to the handover.
