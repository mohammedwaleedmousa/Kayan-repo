# QA Rubric — Brand Identity Pack
*(RP-001 · layer-3 QA · the exact lines the submission letter checks)*

Score each ≥4.0 to pass. Independent QA reviewer (not the designer).

FILES & TECHNICAL
- [ ] Logo opens correctly in AI, SVG, and PNG at all sizes; transparent PNG clean-edged
- [ ] Colour values documented in HEX, RGB, and CMYK; consistent across all files
- [ ] Fonts named with licence notes; no unlicensed/unclear fonts used
- [ ] Stationery print-ready (bleed, margins, resolution ≥300dpi)

BRAND GUIDE
- [ ] Covers: logo usage, minimum size, clear space, colour, type, misuse examples
- [ ] 12 pages, on-brand, legible, exportable
- [ ] A non-designer could follow it to use the brand correctly

SOCIAL KIT
- [ ] Profile + cover at correct current dimensions
- [ ] 3 templates genuinely editable, not flattened

COMPLETENESS & PROMISE
- [ ] Every item in the client description is present
- [ ] Matches the direction the client chose on day 4 (documented)
- [ ] No scope creep silently added or dropped

If any line < 4.0: back to the pod with specific notes before the submission letter.
